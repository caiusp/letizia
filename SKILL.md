# Letizia Zunarelli Website Skill

Guidelines and information for managing, editing, and expanding the website for **Dott.ssa Letizia Zunarelli - Biologa Nutrizionista**.

## Project Architecture
- **Repository**: `caiusp/letizia`
- **Tech Stack**: Vanilla HTML5, CSS3, JavaScript (ES6)
- **Structure**:
  - `index.html`: Main landing page including Hero, About, Services, Google Reviews, and Contact Form.
  - `style.css`: Modern responsive design system with CSS custom properties.
  - `main.js`: Navigation logic, micro-interactions, modal management.
  - `privacy-policy.html` & `cookie-policy.html`: Legal documentation.
